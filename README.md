# Hospital-Management-System---V2

Hospital Management System V2 is a full-stack web app designed to bring order to hospital chaos.
From appointment booking to treatment history, it connects Admins, Doctors, and Patients through a secure,
role-based system built using Flask, VueJS, SQLite, Redis, and Celery.
Automated reminders, monthly reports, and async exports keep everything moving quietly in the background.
